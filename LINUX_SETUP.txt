Optiview — Linux / WSL
======================

Linux (Ubuntu or WSL) is the backend:
- login
- cameras
- live
- talk
- alert
- record
- playback files

Windows is the screen.

First login (created automatically)
  username: admin
  password: 1290

WSL (this Windows PC)
1. Open Ubuntu WSL
2. bash linux/wsl-setup.sh
3. bash ~/optiview/linux/wsl-start.sh
4. Windows Optiview → Remote server → 127.0.0.1 → Connect
5. Sign in: admin / 1290

Ubuntu server
1. python scripts/build_linux_tar.py
2. Copy the .tar.gz to Ubuntu
3. tar -xzf optiview-linux-*.tar.gz && cd optiview && bash linux/install.sh
4. Windows: Remote server → that IP → Connect

Do not open a browser. Do not change nginx, MySQL, or ports 22 / 8000 / 8081.

API port: 8080
